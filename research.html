Research

My doctoral research explores semantic simultaneous localisation and mapping (SLAM), situational awareness, and collaborative missions for unmanned aerial vehicles (UAVs).

Focus areas

SnT, University of Luxembourg, Kirchberg · Advisor: Prof. Dr Holger Voos · Nov 2025 - present.

Semantic relational SLAM

The aim is to move beyond purely geometric mapping so that a UAV can reason about objects, places, and the relations between them while it localises and maps. Current work covers C++ and Python implementation with OpenVINS-based estimation running on embedded Linux, using Raspberry Pi hardware with camera and IMU sensing.

  • Semantic SLAM
  • OpenVINS
  • C++
  • Python
  • Embedded Linux

Situational-awareness architectures for UAVs

The aim is an onboard architecture that turns sensing into an understanding of the situation in order to support navigation decisions. Current work covers ROS 2 and PX4 integration, Docker-based tooling, Kalibr camera and IMU calibration, and testing across simulation, laboratory, hardware, and flight settings.

  • ROS 2
  • PX4
  • Kalibr calibration
  • Docker
  • Flight testing

Collaborative missions

The longer-term direction is for teams of UAVs to conduct collaborative missions using shared semantic maps, resource-efficient navigation, and mission-aware coordination.

  • Shared semantic maps
  • Resource-efficient navigation
  • Mission-aware coordination
